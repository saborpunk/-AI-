真实运行发现两处问题并修复：JDK 默认尝试 h2c 升级，Uvicorn 输出协议/缺少 WebSocket 库警告，改为明确 HTTP/1.1，无需安装 WebSocket；PowerShell 5 的 ErrorDetails.Message 在部分 HTTP 错误中为空，冒烟脚本增加读取 ResponseStream 的兼容分支。故障演示中停止 Python 后正确得到 503/AI_UNAVAILABLE。

代码核心是 DraftController、PythonDraftClient 和 mock_generator.py；完整文件职责、数据流及五个知识点见第二阶段说明。完成后等待确认，不实施下一阶段。
